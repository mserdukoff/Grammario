# Language Learning App

This is a Next.js application designed to help users learn grammar in foreign languages. It uses OpenAI's GPT-4 model to analyze sentences and provide detailed grammatical information, including English translations for each word.

## Prerequisites

- Node.js (v14 or later)
- npm (v6 or later)

## Setup

1. Clone the repository:

2. Install dependencies:
   ```bash
   npm install
   ```

3. Set up environment variables:
   Create a `.env.local` file in the root directory with:
   ```bash
   # OpenAI API key (required for grammar analysis and translations)
   OPENAI_API_KEY=your_openai_api_key_here
   ```
